# Credits and inspiration

This skill was built for personal and educational use. Its ideas come from:

1. **Jacob Bushong: Claude Certified Developer Foundations (CCDV-F) course** (Udemy / certmasterclass.com).
   *Complete CCDV-F certification prep: all 8 domains: agents and workflows, applications and
   integration, Claude Code, evals/testing/debugging, model selection and optimization, prompt and
   context engineering, security and safety, tools and MCPs.*
   The interview flow, tier decision, guardrail rules and eval approach in `decision.md`,
   `guardrails.md` and `evals.md` are organized around the course's domains. They are written
   in our own words; no course material is copied here.
   Course: https://certmasterclass.com/certification/claude-certified-developer-foundations

2. **"90% of Developers Don't Know These 20 AI Agent GitHub Repos"** by neuraldev (Medium).
   https://medium.com/@neuraldev/90-of-developers-dont-know-these-20-ai-agent-github-repos-1b43b1882b80
   It inspired building on open-source agent repos. Note: the 20 repos in `integrations.md` were
   picked separately and may not match the article's list.
